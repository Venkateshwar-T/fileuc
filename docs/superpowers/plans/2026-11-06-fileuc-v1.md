# FileUC v1 Implementation Plan (Revised)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a lightweight, tray-less Windows file converter daemon in Rust that activates on `Ctrl + Drag` in File Explorer, displays an animated radial donut menu at the cursor via `tiny-skia`, and executes in-place conversions for images, PDFs, and archives.

**Architecture:** A single raw Win32 HWND serves as both the OLE drop target and the donut rendering surface — Explorer's drag enters it, the donut is painted on it with `tiny-skia` via `UpdateLayeredWindow`, and the drop lands on the same window. A background daemon owns the Win32 message loop on the main thread, which pumps low-level mouse hooks and COM drag events together. Conversions run on a background thread pool. A Slint settings window spawns on a separate thread when requested.

**Tech Stack:** Rust (2021 edition), `windows` crate (Win32 HWND, WH_MOUSE_LL, COM `IDropTarget`, WIC, `UpdateLayeredWindow`), `tiny-skia` (CPU rasterization to premultiplied BGRA pixmap), `slint` (settings UI on a separate thread), `image` + `resvg` + `lopdf` + `pdf-writer` + `zip` (conversion pipeline).

**Spec:** `C:\Users\Sharad Chand\.gemini\antigravity-cli\brain\4c66a113-234f-4a94-9202-a0919434336f\fileuc-design.md`

## Global Constraints

- **Platform Target:** Windows 10/11 x86_64 only.
- **System Tray:** Zero system tray icons; daemon is invisible.
- **Single Window:** The donut HUD window IS the OLE drop target. One HWND, not two.
- **Drop Safety:** `IDropTarget::Drop` must ALWAYS set `*pdwEffect = DROPEFFECT_COPY`. Explorer must never delete or move source files.
- **Overwrite Policy:** Never silently overwrite; conflicting names append ` (2)`, ` (3)`, etc.
- **Resource Footprint:** Idle RAM target < 20 MB; 0% idle CPU when HUD is not visible.
- **Thread Model:** Main thread runs the Win32 message loop (hooks + COM + HUD rendering). Conversions run on a background thread pool. Slint settings window runs on a dedicated thread.

## Review Focus

1. **Explorer Rubber-band Selection (drag with no files):** `DragEnter` may receive no `CF_HDROP`. The window must stay invisible, report `DROPEFFECT_NONE`, and close on mouse release. Test added to Task 3.
2. **Multi-monitor DPI Scaling:** The window must use physical device pixels from `GetCursorPos` and `MonitorFromPoint` to position itself correctly on any monitor. Test added to Task 3.
3. **Drop in Center Hole or Outside:** `IDropTarget::Drop` fires regardless of where the cursor is within the window. The drop handler must hit-test and only convert when the cursor is on a slice. Otherwise, report `DROPEFFECT_NONE` and clean up. Test added to Task 4.
4. **Read-only / Locked Source Files:** Conversions that fail to open the source must return a `ConvertError::SourceLocked` with the path. The HUD shows `✕` + reason. Test added to Task 6.
5. **Re-launching `fileuc.exe` While Running:** Second instance detects mutex, sends `OpenSettings` via named pipe, exits immediately. Test in Task 1.
